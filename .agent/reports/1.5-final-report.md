## Сводка

Подготовлена установка модуля доставки ApiShip 1.2 (OpenCart 3.x) в проект eridanus-opencart. Модуль совместим с OpenCart 3.0.3.2, конфликтов OCMOD с существующими модификаторами нет, все якоря модификатора присутствуют в реальных файлах проекта. Код подготовлен в ветке `feat/apiship-install`: в корень репозитория добавлены zip-архив и распакованный исходник `apiship-1.2_3.x.ocmod/` (по образцу задачи 1.4 Measoft).

**Главный открытый вопрос — токен.** Заказчик предоставил OAuth-токень Яндекса `y0__...`. Уточнено по доке ApiShip (`https://docs.apiship.ru/docs/delivery-services/list-delivery-services/yataxi/`): этот токен **нужен**, но вводится **в ЛК `apiship.ru`** при подключении службы «Яндекс.Доставка» (поля: ИНН, Токен, Страна = Россия), а **не** в модуле OpenCart. В модуль вводится отдельный **токен ApiShip** с главной страницы ЛК `apiship.ru`. Оба значения — секреты, в репозиторий не попадают.

## Известные пробелы

1. **Токены (порядок ввода).** Нужны два разных ключа в двух местах:
   - **OAuth-токен Яндекса `y0__...`** → вводит заказчик в **ЛК `apiship.ru`** при создании подключения «Службы доставки → Яндекс.Доставка» (обязательные поля: ИНН, Токен = `y0__...`, Страна = Россия; опционально «Идентификатор склада» = код точки Планерная 47, запрашивается у менеджера Яндекса).
   - **Токен ApiShip** → копируется заказчиком с главной страницы ЛК `apiship.ru` и вводится **в модуле OpenCart** в поле `shipping_apiship_token`.
   Без подключения Яндекса в ЛК ApiShip (первый токен) и без токена ApiShip в модуле (второй) — расчёт и экспорт не заработают.
2. **Возвраты на ПВЗ Планерная 47** в модуле как отдельное поле не настраиваются — настраиваются в ЛК ApiShip (правила возврата) и/или на стороне провайдера.
3. **Наложенный платёж** (`cash_on_delivery_payment_methods`) точно работает только при включённой загрузке доставок после оплат в Simple.
2. **Возвраты на ПВЗ Планерная 47** в модуле как отдельное поле не настраиваются — настраиваются в ЛК ApiShip (правила возврата) и/или на стороне провайдера.
3. **Наложенный платёж** (`cash_on_delivery_payment_methods`) точно работает только при включённой загрузке доставок после оплат в Simple.

## Ручные шаги после деплоя на сервер

### Часть A — в ЛК `apiship.ru` (делает заказчик, до настройки модуля)

1. Зарегистрироваться/войти в ЛК `apiship.ru`.
2. **Службы доставки → Яндекс.Доставка →** создать подключение:
   - **ИНН** компании-отправителя,
   - **Токен:** `y0__...` (OAuth-токен Яндекса от заказчика),
   - **Страна:** Россия,
   - при необходимости: «Идентификатор склада» (код точки приёма Планерная 47 — запросить у менеджера Яндекса), «Автоподтверждение», reDelivery.
3. Скопировать **токен ApiShip** с главной страницы ЛК.

### Часть B — модуль OpenCart (на сервере)

4. **Установить модуль:**
   - Extensions → Installer → Upload → выбрать `apiship-1.2_3.x.ocmod.zip` → Install.
   - Если ругается на FTP/fileowner — установить вручную: распаковать `upload/*` в корень сайта, `install.xml` переименовать в `system/apiship.ocmod.xml`.
5. **Применить модификатор:**
   - Extensions → Modifications → найти «ApiShip» → кнопка **Refresh** (правый верх).
   - Очистить кэш: Dashboard → шестерёнка в правом верхнем углу (Clear theme/JS/SASS cache).
6. **Включить и настроить:**
   - Extensions → Extensions → фильтр типа = **Shipping** → найти «Расчёт доставки ApiShip» → **Enable** → **Edit**.
   - Вкладка «Основные»: `shipping_apiship_token` (**токен ApiShip** из ЛК, не `y0__`), режим Normal/Debug, статус Enabled.
   - Вкладка «Адрес»: страна/регион/город/улица/дом/офис = `197373, СПб, Планерная 47`; контакты отправителя (ФИО, телефон, email, ИНН, организация).
   - Вкладка «Шаблоны»: при желании иконки/ссылки ПВЗ и курьера; галка «Все ПВЗ на одной карте».
   - Карта ПВЗ: `shipping_apiship_yandex_api_key` (ключ Яндекс.Карт JS API).
   - Габариты/вес по умолчанию (`parcel_*`, `package_weight`).
   - Гео-зона = Россия; `tax_class`, `sort_order`, `prefix`, `include_fees`.
   - Вкладка «Провайдеры»: для **«Яндекс Доставка»** отметить `pickup_type` (ПВЗ) и `courier_type` (курьер); при «Привоз на склад» вставить код точки приёма Планерная 47 (из справочника ПВЗ в ЛК ApiShip).
   - Вкладка «Статусы»: `export_status`, `cancel_export_status`, групповой экспорт, `mapping_status` (сопоставить ApiShip↔OpenCart + «Оповестить»), `paid_orders`.
   - Наложенный платёж: `cash_on_delivery_payment_methods` (только при включённой загрузке доставок после оплат в Simple).
7. **Cron** (на сервере, через `cron_key` из настроек модуля):
   - `export_cron_url` — групповой экспорт заказов (раз в час/день);
   - `import_cron_url` — подтягивание трек-статусов.
8. **Проверка:** оформить тестовый заказ с доставкой в ПВЗ и курьером; в карточке заказа нажать «Выгрузить в ApiShip» → убедиться, что в ЛК ApiShip появилось отправление и оно ушло в Яндекс Доставку.
