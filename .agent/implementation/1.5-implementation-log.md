## Открытые пункты

1. Подтвердить у заказчика токен: нужен **токен ApiShip** из ЛК `apiship.ru` (не `y0__`). Без него модуль установлен, но нефункционален.
2. После деплоя на сервер: Extensions → Installer → загрузить `apiship-1.2_3.x.ocmod.zip` → Extensions → Modifications → Refresh → Extensions → Extensions → Shipping → включить «Расчёт доставки ApiShip» → Edit.
3. В настройках модуля заполнить: токен ApiShip, режим, адрес отправителя (`197373, СПб, Планерная 47`), контакты отправителя, габариты по умолчанию, геозона (Россия), для провайдера «Яндекс Доставка» включить `pickup_type` (ПВЗ) и `courier_type` (курьер) + код точки приёма Планерная 47, маппинг статусов, наложенный платёж (Simple), ключ Яндекс.Карт JS.
4. Настроить cron на сервере для `export_cron_url` (групповой экспорт) и `import_cron_url` (трек-статусы) с `cron_key`.
5. Возвраты на ПВЗ Планерная 47 настраиваются в ЛК ApiShip (в модуле отдельного поля нет).
