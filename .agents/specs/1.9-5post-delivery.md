## Цель

Подключить «Доставку через Пятёрочку (постаматы и кассы)» — сервис **5Пост
(FivePost, X5 Group)**. Основной маршрут — провайдер «5Пост» в ApiShip (по
образцу Яндекс Доставки из задачи 1.7), без написания нового кода.

## Контекст

- Заказчик попросил подключить доставку через Пятёрочку (постаматы и кассы)
  и выдал «consumer key» (2026-09-01). Ключ выдаётся 5Пост при заключении
  договора; шлюз X5 Omni построен на Apigee, где ключ так и называется.
  Значение будет храниться в `.secrets/5post.md` (заготовка создана, ждём
  вставки значения вместо `REPLACE-ME`).
- Модуль ApiShip 1.2 уже боевой: Яндекс.Доставка подключена (задачи
  1.5/1.7/1.8), экспорт заказов, маппинг статусов и cron настроены.
- ApiShip и 5Пост — официальное партнёрство: магазины, интегрированные с
  ApiShip, подключают 5Пост ускоренно (заявлялось «до одного дня»).
- 5Пост — выдача в постаматах и на кассах магазинов «Пятёрочка»
  (это и есть формулировка заказчика).

## Требования

1. **R1.** Получить у заказчика значение consumer key (и при наличии
   consumer secret, partnerId), внести в `.secrets/5post.md`.
2. **R2.** Подключить службу доставки 5Пост в ЛК `apiship.ru`
   (Службы доставки → 5Пост); при запросе кредов использовать ключ из
   `.secrets/5post.md`; зафиксировать connection id (аналог id=39312 у Яндекса).
3. **R3.** В модуле (админка → Расширения → Доставка → ApiShip → «Параметры
   отгрузки в службы доставки») включить провайдера 5Пост. Способ сдачи
   груза уточнить: у 5Пост своя точка приёма/склад в СПб (точка Яндекса
   1043536 «Планерная 47» к 5Пост отношения не имеет) — нужен свой pointInId
   из справочника ЛК либо курьерский забор, по факту доступных опций.
4. **R4.** Вкладка «Параметры сопоставления статусов»: сопоставить статусы
   5Пост ↔ OpenCart, включить «Оповестить» для клиентских событий.
5. **R5.** Проверить чекаут: методы `point_5post_*` с реальными тарифами,
   выбор постамата/кассы в виджете ПВЗ (список/карта).
6. **R6.** Приёмочный тест: тест-заказ (пометка «TEST AI») → кнопка
   «Выгрузить в ApiShip» → отправление видно в ЛК ApiShip (и в ЛК 5Пост,
   если доступен), статусы возвращаются в заказ.
7. **R7.** (Резерв) Если провайдер 5Пост в ApiShip недоступен/не подходит —
   прямая интеграция: официальный модуль iPol «5Пост» для OpenCart или прямое
   API (схема авторизации — в analysis). Отдельная оценка объёма работ.

## Критерии приёмки

- A1. Consumer key (+ доп. креды) внесены в `.secrets/5post.md`.
- A2. Провайдер 5Пост подключён в ЛК ApiShip, виден в модуле (AJAX-вкладка
  «Провайдеры»).
- A3. В чекауте доступны методы 5Пост (постаматы/кассы) с реальными
  тарифами для тест-адреса.
- A4. Маппинг статусов 5Пост настроен, «Оповестить» включён.
- A5. Тест-заказ выгружен в ApiShip, отправление видно в ЛК, статусы
  синхронизируются.
- A6. Документы 1.9 (analysis/implementation/report) оформлены,
  INDEX/CHANGELOG обновлены.
