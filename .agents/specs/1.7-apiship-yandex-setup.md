## Требования

1. **R1.** Заменить токен на реальный **токен ApiShip** (с главной страницы ЛК
   `apiship.ru`). `y0__…` при этом вводится клиентом в ЛК `apiship.ru`
   (Службы доставки → Яндекс.Доставка: ИНН, токен, страна Россия) — без этого
   экспорт в Яндекс не заработает даже с корректным токеном модуля.
2. **R2.** Вкладка «Параметры отгрузки в службы доставки»: для «Яндекс
   Доставка» включить ПВЗ (`pickup_type`) и курьера (`courier_type`); при
   «Привоз на склад» — код точки приёма Планерная 47 (из справочника ПВЗ
   ЛК ApiShip, запросить у менеджера Яндекса при отсутствии).
3. **R3.** Вкладка «Параметры сопоставления статусов»: сопоставить статусы
   ApiShip ↔ OpenCart, включить «Оповестить» для клиентских событий.
4. **R4.** Заменить тестовые контакты отправителя (`TEST …`,
   `+70000000000`, `ai_agent@local.com`) на реальные данные клиента
   (организация, ИНН, ФИО, телефон, email).
5. **R5.** Приёмочный тест (B8 из 1.5): тестовый заказ с ПВЗ и курьером
   (помечать «TEST AI»), проверка расчёта в чекауте, кнопка «Выгрузить в
   ApiShip» в карточке заказа, появление отправления в ЛК ApiShip.
6. **R6.** Cron (пользователь, на сервере): `export_orders` и
   `import_orders` с `key=vkI33vDy7c` (URL-ы в настройках модуля).
7. **R7.** Ключ Яндекс.Карт JS (`shipping_apiship_yandex_api_key`) — при
   наличии у клиента (карта ПВЗ); без него список ПВЗ работает, карта нет.
8. **R8.** Наложенный платёж — по решению клиента (зависит от Simple:
   загрузка доставок после оплат).
