# Спека 1.23 — Раунд 3 фидбека: заказ без ПВЗ, медленный чекаут, адрес постамата

Дата: 2026-10-15. Статус: код подготовлен (ждёт push/pull + постдеплойная верификация).

## Вход (от заказчика через Максима)

1. **КРИТИЧНОЕ**: заказ #6728 оформлен с «самовывоз Яндекс» **без выбранного пункта** —
   заказ прошёл. Требование: без пункта (Яндекс и 5Пост) заказ не принимается;
   при курьерской доставке без адреса — тоже нельзя идти дальше.
2. **Чекаут думает по 5–10 сек** при любом добавлении/удалении/изменении/вводе —
   раньше было быстрее.
3. **Адрес постамата 5Пост**: где-то не показывается (скриншот 1), где-то есть
   (скриншот 2) — «чтобы никто не путался, откуда забирать, или как это работает».

## Диагноз

1. Валидация «выберите ПВЗ» существовала только в **теневом контроллере**
   `system/storage/modification/.../simplecheckout_shipping.php`, а контроллерная
   подмена modification на этой сборке неактивна (правило 1.18) — проверка никогда
   не исполнялась. Более того, тень синтаксически битая: OCMOD вставил if внутрь
   списка параметров `validator($shippingMethod)`. Модуль apiship кодирует
   «пункт не выбран» подстрокой `error` в коде метода (`apiship.point_..._error_...`),
   а у Simple для этого есть штатный хук `validator()` (блокирует заказ текстом ошибки).
2. Замеры прямых POST-сохранений чекаута: тёплый кэш 1.3–1.6с, **холодный (первое
   сохранение новой сессии/города/по истечении 10 минут) 4.3–8.4с**. Причина: кэш
   ApiShip (`lists/points`, калькулятор) — **сессионный** (`$_SESSION`), TTL 10 минут:
   у каждого нового посетителя и каждые 10 минут — последовательные холодные вызовы
   API ApiShip (постраничная выгрузка пунктов). Теней на библиотеку нет — правится оригинал.
3. Живая проверка выбора пунктов (set_point/get_points + рендер чекаута): **после
   выбора пункта адрес есть в названии способа у обоих провайдеров** (5Пост-постамат:
   «…Санкт-Петербург, пр-кт Индустриальный, д.30 корпус к. 23, офис 23…»), и он же
   попадает в адрес заказа (address1). «Адреса нет» = состояние **пункт не выбран**
   («выбрать ПВЗ») — то самое, при котором до фикса проходил заказ. Отдельного бага
   отображения нет.

## Deliverable

- Портированная валидация в оригиналы контроллеров (ПВЗ без пункта + курьер без адреса).
- Общий файловый кэш ApiShip (справочники 6ч, калькулятор 30мин) в библиотеке.
- Ответ заказчику: как работает адрес пункта (появляется после выбора; заказать без
  пункта больше нельзя).
