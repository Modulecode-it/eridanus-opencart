# 0.3 Перенос `.agent/` → `.agents/` и перевод на русский

**Задача:** 0.3-agents-folder-rename
**Дата:** 2026-08-18
**Статус:** в работе

## Цель

Переименовать папку системы памяти из `.agent/` в `.agents/` без потери git-истории, обновить все ссылки в проекте на новую папку и перевести все агентские файлы, оставшиеся на английском, на русский (включая корневой `AGENTS.md`).

## Область

- `git mv .agent .agents` — перенос всех 68 отслеживаемых файлов.
- Обновление ссылок `.agent/` → `.agents/` в `.agents/**`, корневом `AGENTS.md` и `agent-deploy-kit/**`.
- Перевод на русский: корневой `AGENTS.md`, `.agents/templates/agents-root.md`, скилл `.agents/skills/graphify/` (SKILL.md + 8 файлов `references/`), синхронная копия скилла в `agent-deploy-kit/optional/graphify/skill/`, шаблон `agent-deploy-kit/core/templates/agents-root.md`.
- Не трогать: `agent-memory-v2/`, `agent-memory-v2.zip`, `agent-memory-v2.prompt.md` (незакоммиченный прототип v2 со своей внутренней структурой `.agent/`), сторонний код (`admin/view/javascript/summernote/`), логи `storage79/`, сгенерированный `graphify-out/`.

## Требования

- История git сохранена (перенос через `git mv`, статус `R`, не D+A).
- После переноса в живых файлах проекта не осталось ссылок на старый путь `.agent/`.
- Технические идентификаторы, CLI-команды, флаги, пути вывода, блоки кода и YAML-поле `name: graphify` остались без перевода.
- Frontmatter SKILL.md остался валидным YAML.
- `agent-deploy-kit/` (источник развёртывания) ссылается на `.agents/`, чтобы будущие развёртывания не воссоздавали старый путь.
- Документы задачи 0.3 созданы в новой папке `.agents/`.

## Критерии приемки

- `git status` показывает переименования (R), а не удаления+добавления.
- `grep -rn "\.agent/"` по `.agents/`, `agent-deploy-kit/`, `AGENTS.md` — пусто.
- Корневой `AGENTS.md` на русском и ссылается на `.agents/`.
- Скилл graphify полностью на русском, frontmatter валиден, `.graphify_version` на месте.
- `INDEX.md` дополнен строкой 0.3, `CHANGELOG.md` — записью [1.0.4].
- `graphify update .` выполнен без ошибок.

## Риски

- Двойная замена (получить `.agentss`) — исключена паттерном `\.agent/` (слэш сразу после `agent`).
- Нарушение работы скилла graphify из-за перевода description — описание остаётся человекочитаемым триггером, имя не меняется.
- Хук `hooks.json` (graphify hook-check) не содержит путей `.agent` — не затронут.
