## Требования

1. Идемпотентность: перед каждым действием проверять состояние целевого файла; сравнение с донором — только через `diff --strip-trailing-cr` (донор — LF, наши файлы — CRLF). Уже присутствующее улучшение не дублировать.
2. Запрет Laravel-утечек: стоп-лист терминов — `artisan`, `composer`, `Eloquent`, `Blade`, `Livewire`, `Horizon`, `Redis`, `PostgreSQL`, `миграц`, `Pest`, `PHPUnit`, `sail`, `vendor/`, `Planfix`, `RBAC`, `2FA`, `Livewire-компонент`, `phpunit.xml`.
3. Проектные файлы не перезаписывать: `STACK.md`, `PROJECT_STRUCTURE.md`, `INDEX.md`, `CHANGELOG.md`, `hooks.json`, скилл `graphify`, задачи в `specs/analysis/implementation/reports` — только дополнение по правилам.
4. Все новые/обновлённые файлы в `.agents/` — с CRLF-концовками строк.
5. PAT для git-sync: по решению пользователя — взять PAT аккаунта `Modulecode-it` из SKILL.md донора (наш репо принадлежит тому же аккаунту). Remote у нас SSH, поэтому в командах скилла URL HTTPS указывается явно.
6. Имя ветки и remote — из нашего репо: `origin`, `main`.
