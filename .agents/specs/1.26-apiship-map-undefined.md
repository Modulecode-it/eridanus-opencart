# Задача 1.26 — Карта ПВЗ не открывается после ввода региона/города (ApishipMap is not defined)

**Задача:** 1.26-apiship-map-undefined
**Дата:** 2026-11-18
**Статус:** код подготовлен (ждёт деплоя на dev/прод и верификации)

## Цель

Устранить ошибку чекаута: после ввода региона и города (гость, свежая сессия) клик «выбрать ПВЗ» у способов ApiShip не открывает карту пунктов. В консоли браузера:

```
Uncaught ReferenceError: ApishipMap is not defined
    at Object.success (eval at globalEval (jquery-2.1.1.min.js:2:2536), <anonymous>:60:26)
```

Сопутствующий шум (не блокирует): `api-maps.yandex.ru/2.1/?lang=ru_RU&ns=cdekymap` → «(Yandex Maps JS API): Invalid API key».

## Область

- `catalog/view/javascript/apiship.js` — виджет карты ApiShip (класс `ApishipMap`);
- `apiship-1.2_3.x.ocmod/upload/catalog/view/javascript/apiship.js` — копия в пакете;
- контекст: Simple-чекаут, AJAX-перегрузка блока доставки, jQuery 2.1.1.

## Требования

1. Клик «выбрать ПВЗ» открывает модалку с картой в сценарии «первое появление apiship-котировок через AJAX-перегрузку блока» (введён город после загрузки страницы).
2. Регрессий в сценарии «apiship-котировки уже были при первичном рендере страницы» (обычная `<script>`-загрузка файла) — нет.
3. Копия файла в пакете `apiship-1.2_3.x.ocmod/upload/` синхронна с рабочей.

## Ограничения

- Правка минимальная, только механика объявления класса; логика виджета не меняется.
- Проблема `ns=cdekymap` «Invalid API key» (CDEK-виджет, `catalog/controller/event/cdekshipping.php`) — вне области, отдельный кандидат на чистку.

## Критерии Приёмки

- На dev после деплоя: свежая сессия → товар → чекаут → страна/регион/город → «выбрать ПВЗ» → модалка с картой открывается, `typeof ApishipMap === 'function'`, ошибок в консоли нет (кроме несвязанного cdekymap-шума).
- `node --check` обоих файлов проходит; копии идентичны.
