## Рекомендация Максиму по почте на dev (обновлено 2026-10-12 после просмотра compose)

В compose проекта уже есть **mailpit** (`eridanus-mailpit`, web UI `127.0.0.1:8025`,
SMTP-порт 1025) — почтовая ловушка. Проблема заказчика «письмо восстановления не
приходит» — потому что настройки почты в БД (копия боевой) указывают на прод-SMTP,
которого на dev нет. Достаточно в OpenCart на dev выставить SMTP-хост на mailpit
(System → Settings → Mail: Mail Protocol SMTP, SMTP Hostname `eridanus-mailpit`
(или сервисное имя из сети compose), SMTP Port 1025, без авторизации) — все письма
(восстановление пароля, заказы) будут ловиться в UI mailpit, можно показывать
заказчику. Настоящая отправка (info@eridanus.ru через Яндекс SMTP, app-password)
нужна только на проде — внести в чек-лист 1.21. Осторожность прежняя: БД dev —
копия боевой, письма реальным клиентам не триггерить (mailpit наружу не шлёт —
безопасно по определению).
