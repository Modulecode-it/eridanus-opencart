### Ключевые находки (наследие для эксплуатации)

1. **Наложка у Яндекса через этот модуль не работает без доработки**: экспресс-тарифы
   её запрещают вовсе, а на обычных курьерских ApiShip подставляет paymentMethod='card',
   который Яндекс-курьер не принимает (только наличные). Модуль способ оплаты наложки
   не передаёт. Рабочая схема сейчас — предоплата (для теста включена через «оплаченные»
   статусы). Решение за клиентом: предоплата / наложка только в ПВЗ / доработка модуля.
2. При выгрузке обязателен вес заказа (целое число граммов) — пустое поле даёт ошибку
   валидации ApiShip; в карточке заказа заполнять «Вес всего заказа» (тест: 500 г).
3. Кэш справочников модуля — PHP-сессия, 10 минут: изменения в ЛК (подключения СД)
   проявляются в админке с задержкой.
4. Старые методы доставки в чекауте ещё активны (flat, measoftcourier ×2) — MeaSoft
   (Е-Логистик закрыта клиентом) в backlog на отключение.
5. Кнопки карточки заказа/добавления в корзину местами чувствительны к способу клика
   (браузерный плагин) — рабочий обход для выгрузки: прямой GET на роут экспорта с
   сессией админки (см. implementation log).
