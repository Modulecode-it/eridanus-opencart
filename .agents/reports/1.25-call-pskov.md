# 1.25 — Созвон с заказчиком (сессия 4) + кейс Пскова

**Задача:** 1.25-customer-feedback-round3
**Дата:** 2026-11-10
**Контекст:** созвон с заказчиком по удалённому рабочему столу; после — прод-проверка кейса «Псков». Код не менялся.

## Итог созвона

1. **«Карта не открывается» у заказчика — Касперский.** Блокировался виджет карты ПВЗ на чекауте; после отключения Касперского всё заработало. Клиентский фактор, инцидент закрыт (рекомендация заказчику — добавить eridanus.ru и виджет в доверенную зону антивируса).
2. **Новый кейс: Псков.** Скрин заказчика: регион «Псковская область», город Псков, оплата картой → из доставки только «Самовывоз 5Post 3-5дн. 363р.», Яндекса нет вообще (ни ПВЗ, ни курьера), «Оплата при доставке» не предлагается.

Карта 5Post для Пскова (та же сессия, `route=extension/shipping/apiship/get_points`, code `apiship.point_x5_439_error_2`): **61 пункт**, координаты Пскова (57.81/28.27…), 363р., 3–5 дн. — самовывоз 5Post в Пскове полностью рабочий.

## Диагноз

**Провайдер yataxi (Яндекс.Доставка) в ApiShip не возвращает тарифы для адреса, отрезолвленного в Псковскую область — ни deliveryToPoint, ни deliveryToDoor.** Остаток = 5Post. Сайт показывает ровно то, что отдал агрегатор: код работает штатно. Аналог кейса «Ленинградская область» (сессия-2), но там курьер Яндекса оставался — здесь yataxi отсутствует целиком.

### Внешнее подтверждение (10.11, ЛК a.apiship.ru → Калькулятор)

Максим вручную прогнал расчёт в ЛК ApiShip (`#/calculator/index`): from = склад СПб (Планерная 47 к 1), to = Псковская обл. / г. Псков, 300 г, 19×15×3, codCost 810. Ответ: **yataxi — `tariffs: []` в обоих типах** (дверь и ПВЗ); x5 — тариф 439 «Стандартный тариф до постамата» 362,55₽, 3–5 дн., **61 pointId** — цифра в цифру совпадает с картой сайта (363р., 61 пункт). Диагноз подтверждён без участия нашего кода: сайт зеркален агрегатору. У самого Яндекса ПВЗ в Пскове есть (dostavka.yandex.ru/pickup-point-pskov) — ограничение на стыке ApiShip↔yataxi. Следующий шаг — чат поддержки ApiShip из ЛК с этим JSON (покрывается ли регион).

Побочные факты:

- **Регион доминирует над городом** (подтверждение сессии-2): «Псков» при регионе «Санкт-Петербург» получает СПб-тарифы и СПб-ПВЗ — покупатель из Пскова с неверно выбранным регионом закажет доставку в пункт СПб по СПб-цене. Кандидат этапа 2: контроль соответствия город↔регион + подсказка «для вашего региона служба недоступна» вместо молчаливого урезания.
- Наложка для зоны 98 скрыта (только карта) — устойчивое поведение, как в ЛО (гео-фильтр `cod`).

## Ответ заказчику (коротко)

Для Пскова сайт показывает все реально доступные способы: самовывоз 5Post (61 пункт в Пскове, 363 р., 3–5 дней) и оплату картой. Пункты и курьер Яндекса для Псковской области не отдаются службой расчёта (ApiShip) — это ограничение покрытия самой Яндекс-доставки через агрегатор, а не сбой сайта. Дополнительно: карта у вас не открывалась из-за Касперского — после отключения работает.
