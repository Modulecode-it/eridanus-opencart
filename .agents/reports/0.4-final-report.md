## Известные Пробелы

- **PAT в `.agents/skills/git-sync/SKILL.md`** — в репозитории плейсхолдер `<GITHUB_PAT>`: пуш с реальным токеном заблокирован GitHub Push Protection (пользователь подтвердил плейсхолдер). Реальный PAT вставляется в локальную копию файла (3 вхождения) и не коммитится; при ротации PAT обновлять локальную копию.
- Команды `git-sync` с явным HTTPS-URL не прогонялись в runtime (push/pull не выполнялись — изменения не закоммичены); синтаксис соответствует рабочему скиллу донора.
- Скиллы `git-sync`/`no-local-testing` задокументированы в `skills/README.md`, но их активация агентом проверится в следующих сессиях.

## Следующие Шаги

1. Закоммитить и задеплоить изменения (по запросу пользователя; скилл `git-sync` — перед push спросить про коммит).
2. При ротации GitHub PAT — обновить `.agents/skills/git-sync/SKILL.md` (3 вхождения).
3. В будущих развёртываниях из `agent-deploy-kit/` учесть, что README системы теперь описывает `skills/` как рабочую папку ZCode-скиллов.

## Осознанные Исключения Стоп-Листа

- Слово «Laravel» встречается один раз в `.agents/README.md` (п.3 «Порядка Работы»: «…стека (OpenCart / Laravel / …)») — универсальное перечисление примеров стеков из кита; текст существовал в нашем файле до задачи и донором не переносился. Голое слово «Laravel» в стоп-лист задачи не входит.
