## Ручные шаги на сервере (выполняет пользователь)

```bash
cd /var/www/eridanus.dev.modulecode.ru/opencart

# 1) Восстановить затёртые патчи Measoft и откатить mode-change шум
git checkout -- .

# 2) Спрятать untracked-файлы (иначе merge откажется их перезаписывать)
git stash push -u -m 'server install artifacts before 1.6 sync'

# 3) Обновиться до актуального main (fetch не делался с момента мержа 1.5)
git fetch origin
git merge --ff-only origin/main

# 4) Контроль: ожидается чистый статус
git status
git log --oneline -3

# 5) Если статус чист — сверить measoft-картинки и удалить подстраховочный stash
md5sum admin/view/image/measoftcourier/*   # сравнить с measoft_oc3.ocmod/upload/admin/view/image/measoftcourier/*
git stash drop
```

Если после шага 4 `git status` показывает modified-файлы — значит серверная
статика новее локального baseline: показать вывод, различия перенести отдельным
коммитом (не терять stash до разбора).
