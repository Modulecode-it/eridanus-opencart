## Текущее Поведение (до задачи)

- Правила (`AGENTS.md` «Главное правило», `STACK.md` «Деплой На Сервер»/«Проверка»,
  `CHECKLISTS.md` п.4, скилл `no-local-testing`, CHANGELOG v1.0.1) запрещали
  HTTP/браузерные запросы к `eridanus.dev.modulecode.ru` из среды агента:
  проверка только через git-коммиты и серверный deploy, выполняемый пользователем.
- Причина запрета (v1.0.1) — риск «агент дёрнет живой сайт локальными тестами».
- Деплой на сервер описывался как серверные git-шаги, выполняемые пользователем;
  про SSH явно не было сказано «запрещён/невозможен».

## Релевантные Файлы

- `AGENTS.md` — секция «⚠️ Главное правило».
- `.agents/STACK.md` — «Проверка» (п.3), «Деплой На Сервер» (п.1).
- `.agents/CHECKLISTS.md` — «Перед Завершением Задачи» п.4.
- `.agents/skills/no-local-testing/SKILL.md` — frontmatter description + тело.
- `.gitignore`, `.agents/templates/`, `.agents/INDEX.md`, `.agents/CHANGELOG.md`.
- Техническая база: плагин browser-use (скиллы `control-browser`,
  `web-gui-tester`, MCP `node_repl`) уже установлен в среде ZCode — донастройка
  не требуется.

## Решения

1. **Запрет браузерных запросов снят, но только для dev-домена.** Запрет
   локального запуска PHP/БД/веб-сервера сохранён без изменений — он про другое.
2. **SSH зафиксирован как недоступный навсегда** (на сервере чужие сайты) —
   серверные шаги остаются за пользователем; агент готовит инструкции.
3. **Креды — в `.secrets/` (gitignored), а не в `.agents/` и не в git.**
   Компромисс: владелец разрешил «хранить в файлах», но репо пушится на GitHub —
   пароль в коммите утёк бы на GitHub. Файл локальный, доступен агенту, в git
   не попадает. Правило «в `.agents` секреты не хранить» не нарушено.
4. **Бекапы — обязательное предложение** перед важными/разрушающими операциями;
   способы: System → Maintenance → Backup → Export (из админки) или Adminer
   (`adminer-4.7.3-mysql.php` в корне сайта). Дампы — локально, не в git.
5. **Отдельный AI-пользователь админки** (рекомендовано `ai_agent`, группа
   Administrator) — база скопирована с боевой, основной аккаунт не светим.

## Риски

- **База = копия боевой**: агент может столкнуться с реальными заказами/клиентами.
  Митигировано правилами R5 (не трогать без одобрения, тестовые сущности
  помечать, скриншоты не коммитить).
- **Утечка кредов через git**: митигировано `.secrets/` в `.gitignore`.
- **Смешение dev/прод**: если сайт станет продакшеном, правила устареют —
  в шаблоне `dev-secrets.md` записано условие отзыва AI-пользователя.
