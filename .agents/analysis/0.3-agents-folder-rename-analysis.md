# 0.3 Анализ: перенос `.agent/` → `.agents/` и перевод

**Задача:** 0.3-agents-folder-rename
**Дата:** 2026-08-18
**Статус:** завершён

## Текущее состояние

- Папка `.agent/` — 68 отслеживаемых файлов (ядро системы памяти, скилл graphify, задачи 0.1–1.5, ADR, шаблоны, промты).
- Ядро системы (README, CORE, RULES, CHECKLISTS, STACK, PROJECT_STRUCTURE, ONBOARDING, INDEX, CHANGELOG) и документы задач уже на русском.
- На английском остались: корневой `AGENTS.md`, `.agent/templates/agents-root.md`, весь скилл graphify (SKILL.md 641 строка + 8 файлов references ~800 строк), заголовок ADR-001.
- `agent-deploy-kit/` (44 файла) — источник развёртывания системы; README/DEPLOY на русском, но ссылается на `.agent/` как целевой путь и содержит английскую копию скилла graphify в `optional/graphify/skill/`.
- `agent-memory-v2/` (+ zip, prompt) — незакоммиченный прототип v2 со своей внутренней `.agent/`; к живой системе не подключён.
- Пустая папка `.agents/` уже существовала в корне (создана заранее).
- Конфигов `.zcode/`, `.claude/`, `.codex/`, `.cursor/` в репозитории нет; `hooks.json` не содержит путей `.agent`.
- Ложные срабатывания поиска: `admin/view/javascript/summernote/summernote.js` (сторонний WYSIWYG), `storage79/logs/contact.log` (gitignored) — не трогать.

## Ссылки на `.agent/`

Всего в живых файлах найдено ~250 упоминаний пути: внутри самой `.agent/**`, в `AGENTS.md`, в `agent-deploy-kit/**` (включая hooks.json.example с упоминанием `.agent/skills/graphify/` в комментарии). Все упоминания имеют вид `.agent/` (с завершающим слэшем) — простая замена `\.agent/` → `.agents/` безопасна и не может задеть уже существующие `.agents/` или породить `.agentss`.

## Варианты и решение

| Вариант | Оценка |
|---|---|
| `git mv .agent .agents` + sed-замена путей | Выбран: сохраняет историю (статус R), атомарен, проверяем grep'ом. |
| Копирование + удаление | Отклонён: рвёт историю файлов. |
| Символическая ссылка `.agent` → `.agents` | Отклонён: лишний слой, проблемы на Windows/деплое. |

Для перевода скилла graphify (~1450 строк) — параллельная делегация субагентам с жёсткими правилами сохранения frontmatter, код-блоков и идентификаторов; живая версия скилла после перевода копируется в `agent-deploy-kit/optional/graphify/skill/` для синхронизации кита.

## Ограничения

- Перевод — только документация и комментарии; исполняемый код, CLI, JSON, промпты Whisper/extraction внутри код-блоков остаются как есть.
- `agent-memory-v2/` не трогаем: его `.agent/` — часть будущей миграции на v2, не живой системы.
