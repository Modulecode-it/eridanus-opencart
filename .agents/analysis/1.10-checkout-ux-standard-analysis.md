## Ответы на вопросы заказчика (по данным кода и админки dev)

### 1) «Выберите адрес» — откуда адрес и почему неполный

- Поле принадлежит Simple (блок «Адрес доставки»; из-за опции «Визуально объединить с
  блоком покупателя» отображается внутри блока «Покупатель»). Языковой ключ
  `text_select_address` (`catalog/language/ru-ru/checkout/simplecheckout.php:35`).
- Значения — адресная книга залогиненного покупателя (`oc_address`) либо значения
  адреса доставки из сессии чекаута; строка форматируется шаблоном Simple
  `{firstname} {lastname}, {city}, {address_1}` (настройка поля `address_id`,
  «Формат адреса в списке значений поля»).
- «, Санкт-Петербург,» = пустые имя/улица, заполнен только город: адрес в сессии/адресной
  книге заполнен не полностью. У аккаунтов lunkinmaks(±.dev) и тестовых (TEST AI Agent,
  AI-Тест Тестов) сохранённых адресов нет — значение пришло из сессии чекаута
  (город без улицы). Код Simple закрыт ionCube — логика проверена по настройкам админки.
- Корневая проблема UX: в наборе полей «Адрес доставки» было только поле «Выберите адрес»,
  полей «Город»/«Адрес» не было вовсе (для гостя их негде заполнить) — при этом гостевой
  заказ был запрещён («Требовать авторизацию», Simple → Общие настройки).
- Исправление: R1 (гостевой заказ) + R4 (добавлены поля Город/Адрес/Индекс/Фамилия/Страна
  в набор полей блока «Адрес доставки»); данные адреса дозаполняются покупателем.

### 2) «Курьерская доставка» и «Доставка до ПВЗ»

- Обе группы — модуль **Measoft 4.3.12** (Е-Логистик), установленный в задаче 1.4:
  - «Курьерская доставка (…)» — `shipping/measoftcourier`, заголовок из настройки
    `shipping_measoftcourier_courier_title`, пункт «Доставка курьером до двери»;
  - «Доставка до ПВЗ» — `shipping/measoftcouriershipping`, заголовок из
    `shipping_measoftcourier_pvz_title»; «Mountain Blue; Невский проспект, 1» — ПВЗ
    тестовой курьерской службы Measoft (тестовый аккаунт login/pass/extra=8).
- В актуальном ТЗ (1.7/1.8) их НЕТ: клиент с Е-Логистик больше не работает
  (spec 1.7: «Клиент с Е-Логистик больше не работает (MeaSoft/задача 1.4 — тестовый
  аккаунт)»). Тарифы «170р./4.5 дней» — тестовые данные, не боевые.
- Решение: оба модуля выключены (R2).

### 3) ApiShip и 5Пост

- Группа «ApiShip» — модуль `shipping/apiship` 1.2 (агрегатор), внутри — Яндекс.Доставка
  (yataxi): «Самовывоз из ПВЗ Яндекс.Доставка …» и «Курьер Яндекс Доставка …». Это и есть
  боевая доставка из ТЗ (задачи 1.5–1.8).
- 5Пост (x5) подключён (задача 1.9: connection 39490, склад, провайдер включён), но
  тарифы в ApiShip ещё не активированы: проверено запросом к калькулятору
  `api.apiship.ru/v1/calculator` 2026-09-01 — `x5: tariffs[] = 0` (у yataxi по 1 тарифу
  на ПВЗ/курьер). Как только ApiShip активирует тарифную сетку, методы `point_x5_*`
  появятся в чекауте автоматически, без доработок.

### 4) Способы оплаты

- В чекауте виден только «Оплата картой на сайте банка» = **Модульбанк** (интернет-эквайринг).
- Установленные платёжные модули (админка → Расширения → Оплата):
  - Включены: Модульбанк; «Оплата при доставке» (cod) — но у cod геозона
    «Москва+Санкт-Петербург», поэтому в чекауте он не показывается для адреса без зоны.
  - Отключены: Банковский перевод (bank_transfer), Оплата наличными, Наложенный платеж СДЭК,
    LIQPAY, PayPal ×3, Бесплатный заказ.
- Включить другие можно в админке (Расширения → Оплата → Edit → Статус: Включено).
  Нюанс: «Оплата при доставке» = наложенный платёж; Яндекс.Доставка наложку без доработки
  не поддерживает (вывод задачи 1.7) — включать только после решения курьерской схемы.

## Состояние настроек до правок

- Simple → Общие настройки: «Требовать авторизацию для оформления заказа» = ВКЛ (гостевой
  заказ запрещён, редирект на /login — `catalog/controller/checkout/simplecheckout.php:20-22`).
- Simple → блок «Адрес доставки»: набор полей = только «Выберите адрес».
- Доставки Включены: ApiShip, Фиксированная стоимость, Самовывоз, Почта России и EMS,
  По весу, Measoft ×2 (в чекауте для СПб показывались Measoft ×2 + ApiShip).
- `shipping_apiship_title` = «ApiShip» (значение по умолчанию из
  `catalog/language/ru-RU/extension/shipping/apiship.php:3`, поле «Название модуля доставки»).
