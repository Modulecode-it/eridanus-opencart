```
avail_button_type               = 0            (button)
avail_default                   = 0            (кастомный шаблон → all_button_id)

block_product                   = .product-thumb
avail_button_athepage_class     = btn btn-primary
avail_button_product_class      = btn btn-primary btn-lg btn-block
avail_button_cart_productpage   = #button-cart
avail_background/border_button_open_notify = 229ac8, avail_text_button_open_notify = ffffff
avail_customer_class            = пробелы (пустой <style> — безвредно)
text                            = Сообщить о поступлении
```

Т.е. кнопка в листинге — `<button class="notify btn btn-primary">` после div
`.avail-button-cart` внутри `.button-group`; JS вешает цвета inline
(background/border/color), поэтому inline-стили сильнее stylesheet без `!important`.

## Замеры кнопки «до» (viewport 1280)

| элемент | w | h | примечание |
|---|---|---|---|
| div.avail-button-cart (hidden) | 0 | 0 | класс `hidden` получает ОБЁРТКА (JS `all_button_id`), не кнопка |
| button.notify btn btn-primary | 156 | **55** | padding 7.5px 12px, line-height 38px, **white-space: nowrap** — span 184px > 156px, текст обрезан |
| иконки wishlist/compare | 52 | 40 | нормальный ряд |

Почему 60% ширины: тема stylesheet.css `.product-thumb .button-group .avail-button-cart.hidden + button {width: 60%}` — специфичность (0,3,1) бьёт медиа-правила `.product-thumb .button-group button {width: 33.33%}` (0,2,1) на ≤1200px и ≤767px ⇒ на планшете/мобиле notify 60% + иконки 33.33%×2 = 126% ⇒ иконки уезжают на вторую строку.
