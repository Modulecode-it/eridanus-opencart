## Изменения

### 1. `system/library/apiship/apiship.php`

- **Причина:** любой ответ без `body.errors` кешировался на 1800с, включая пустой (null-body от сбоя curl) и урезанный — «пропадание» служб до 30 мин у покупателей с той же корзиной (диагноз 1.25-сессии-3, живое подтверждение 1.26).
- **Кратко:**
  - ветка чтения: `sharedCacheGet(..., 1800)` → `(..., 300)` (аргумент декоративный, выправлен для честности) + дополнение комментария;
  - ветка записи: перед `sharedCacheSet` добавлен подсчёт тарифов `deliveryToPoint`/`deliveryToDoor` (провайдер без `tariffs` = 0, зеркалит модель):
    - `0 + 0` → `toLog('shipping_apiship_calculator cache_empty_not_stored', ..., true)` и `return $data` **без записи в кеш**;
    - асимметрия → `$cache_ttl = 120` + `toLog('shipping_apiship_calculator cache_partial_ttl_120', ..., true)`;
    - иначе `$cache_ttl = 300`;
  - `sharedCacheSet($data_key, $data_hash, $data, $cache_ttl)`.
- **Побочные эффекты:** рост числа запросов к калькулятору ApiShip (TTL 300/120 вместо 1800) — принят; форма возврата для вызывающих не изменилась; лог-маркеры пишутся всегда (error=true).

Кода модели/контроллеров/шаблонов/БД/настроек не менялось. Копия пакета `apiship-1.2_3.x.ocmod/upload/system/library/apiship/apiship.php` — без изменений (вендор-оригинал; правки eridanus в него не синхронизируются со времён 1.23 — при обновлении модуля файл сверять руками).
