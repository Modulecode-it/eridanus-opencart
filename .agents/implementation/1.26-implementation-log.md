## Изменения

### 1. `catalog/view/javascript/apiship.js`

- **Причина:** при AJAX-вставке блока доставки файл исполняется через jQuery `_evalUrl`→`globalEval` (indirect eval); декларация `class` не сохраняется после eval → `ReferenceError: ApishipMap is not defined` при клике «выбрать ПВЗ» (первое появление котировок — через AJAX, типично для гостя со свежей сессией).
- **Кратко:** строка 1 `class ApishipMap {` → блок-комментарий на русском + `var ApishipMap = class ApishipMap {`; закрывающая `}` файла → `};`.
- **Побочные эффекты:** нет. `var`-присваивание класса эквивалентно декларации при обычной `<script>`-загрузке; повторные исполнения файла (серверный рендер + AJAX-перегрузки) безвредны.

### 2. `apiship-1.2_3.x.ocmod/upload/catalog/view/javascript/apiship.js`

- **Причина:** идентичная копия пакета — держать синхронной, чтобы переустановка модуля не вернула баг.
- **Кратко:** те же две правки.
- **Побочные эффекты:** нет.

Кода PHP/шаблонов/БД не менялось. Настроек модуля не трогали.
