## Журнал Изменённых Файлов

### `system/library/apiship/apiship.php`

- **Причина:** улица в `to.addressString` заставляла ApiShip геокодировать адрес
  до конкретного дома и урезать `tariff.pointIds` до «ближайших к дому» ПВЗ
  (8–11 точек вместо 664/836 по СПб; у клиента рядом с домом Яндекс-ПВЗ не было —
  метод пропадал целиком). Улица попадала в расчёт только при выборе сохранённого
  адреса (Simple кладёт `address_1` из БД в сессию; при «новом адресе» поле
  скрыто для ПВЗ-методов) — отсюда симптом «сохранённый адрес = ПВЗ пропадают».
- **Кратко:** в `apiship_calculator()` сразу после принудительного
  `$postcode = '';` добавлено `$ext_address = '';` с комментарием
  (eridanus fix 1.28). +8 строк (код + комментарий), логика не тронута.
- **Побочные эффекты:** (а) улица выпадает из хэша кеша калькулятора — записи
  кеша унифицируются до «одна на город+корзину+оплату» (меньше записей, меньше
  шансов на расхождения между адресами одного города); (б) door-тариф считается
  по городу, а не по дому — цена не меняется (подъезд/этаж и так не
  тарифицируются; probe 20.11: deliveryToDoor у x5/yataxi присутствует и без
  улицы с теми же тарифами); (в) старые записи кеша с улицей в хэше догорят
  сами (TTL ≤300с после 1.27) — чистка кеша не требуется.
