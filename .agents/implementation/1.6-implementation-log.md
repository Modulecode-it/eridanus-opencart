**Причина:** Правило `image/` глушло вложенные `image/`-папки — картинки модулей не попадали в git (в т.ч. внутри пакетов задач 1.4/1.5).
**Краткое описание:** `image/` → `/image/` (только корневой каталог товаров), комментарий о запрете убирать ведущий слэш.
**Побочные эффекты:** в `git status` появляются ранее игнорированные вложенные ассеты; все добавлены в этом же коммите.

**Файлы:** 22 файла ApiShip по рабочим путям (`admin/controller|language|model|view/...apiship*`, `catalog/...`, `system/library/apiship/apiship.php`, включая 6 картинок в `image/shipping/`).
**Причина:** Модуль установлен на сервере через Extension Installer (задача 1.5, шаг B4); по модели репо рабочие пути трекаются (образец 1.4).
**Краткое описание:** Копия из `apiship-1.2_3.x.ocmod/upload/` без изменений; сверка blob-хэшей с пакетом — 22/22 OK; md5 серверных файлов — 16+6/16+6 OK.
**Побочные эффекты:** Нет (байтовая идентичность серверу подтверждена).

**Файлы:** 6 картинок `apiship-1.2_3.x.ocmod/upload/{admin/view/image,catalog/view/theme/default/image}/...`.
**Причина:** Дыра задачи 1.5: картинки не попали в git из-за старого правила `image/`.
**Краткое описание:** Добавлены как есть (бинарные).
