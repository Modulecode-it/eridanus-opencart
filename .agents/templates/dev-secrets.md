# Шаблон: креды dev-админки для AI (задача 0.5)

Копию этого файла положить в `.secrets/dev-admin.md` и заполнить.
Папка `.secrets/` добавлена в `.gitignore` — содержимое не попадает в git
(репозиторий пушится на GitHub) и не хранится в `.agents/`.

## Как завести AI-пользователя в админке (делает владелец)

1. `admin` → System → Users → Users → **Add New**.
2. Username: `ai_agent` (или любой другой — синхронизировать с файлом кредов).
3. User Group: **Administrator** (нужен полный доступ для настройки модулей);
   при желании позже создать отдельную группу с урезанными правами.
4. Password: сгенерировать и сохранить; Status: Enabled.
5. Не включать для этого пользователя 2FA/ограничения IP, мешающие браузерной
   сессии агента.

## Формат файла `.secrets/dev-admin.md`

```markdown
# Dev-доступ AI к админке eridanus (НЕ коммитить: .secrets/ в .gitignore)

URL админки: https://eridanus.dev.modulecode.ru/admin/
Username: ai_agent
Password: <пароль>
```

## Правила использования

- Это **dev-сайт**; база — копия боевой: реальные заказы/клиенты не трогать без
  явного одобрения владельца.
- Перед важными/разрушающими операциями предлагать бекап (см. `STACK.md`,
  «Браузерный Доступ к Dev-Сайту (AI)»).
- Если креды сменены — обновить файл; если сайт стал продакшеном — немедленно
  удалить файл и отозвать AI-пользователя.
