# Справочник graphify: добавление URL и наблюдение за папкой

Загружай этот файл, когда пользователь выполнил `/graphify add <url>` или передал `--watch`. Ни то, ни другое не входит в сборку по умолчанию.

## Для /graphify add

Получи URL и добавь его в корпус, затем обнови граф.

```bash
$(cat graphify-out/.graphify_python) -c "
import sys
from graphify.ingest import ingest
from pathlib import Path

try:
    out = ingest('URL', Path('./raw'), author='AUTHOR', contributor='CONTRIBUTOR')
    print(f'Saved to {out}')
except ValueError as e:
    print(f'error: {e}', file=sys.stderr)
    sys.exit(1)
except RuntimeError as e:
    print(f'error: {e}', file=sys.stderr)
    sys.exit(1)
"
```

Замени `URL` на фактический URL, `AUTHOR` — на имя пользователя, если оно указано, `CONTRIBUTOR` — аналогично. Если команда завершается с ошибкой, сообщи пользователю, что пошло не так — не продолжай молча. После успешного сохранения автоматически запусти пайплайн `--update` на `./raw`, чтобы влить новый файл в существующий граф.

Поддерживаемые типы URL (определяются автоматически):
- YouTube / любой видео-URL → аудио скачивается через yt-dlp и транскрибируется в `.txt` при следующем запуске (требуется `pip install 'graphifyy[video]'`)
- Twitter/X → загружается через oEmbed, сохраняется как `.md` с текстом твита и автором
- arXiv → аннотация + метаданные сохраняются как `.md`
- PDF → скачивается как `.pdf`
- Изображения (.png/.jpg/.webp) → скачиваются, Claude vision извлекает содержимое при следующем запуске
- Любая веб-страница → конвертируется в markdown через html2text

## Для --watch

Запусти фоновый наблюдатель, который следит за папкой и автоматически обновляет граф при изменении файлов.

```bash
$(cat graphify-out/.graphify_python) -m graphify.watch INPUT_PATH --debounce 3
```

Замени INPUT_PATH на папку, за которой нужно следить. Поведение зависит от того, что изменилось:

- **Только файлы кода (.py, .ts, .go и т.д.):** сразу повторно запускается AST-извлечение + пересборка + кластеризация, LLM не нужен. `graph.json` и `GRAPH_REPORT.md` обновляются автоматически.
- **Документы, статьи или изображения:** записывается флаг `graphify-out/needs_update` и выводится уведомление запустить `/graphify --update` (требуется повторное семантическое извлечение через LLM).

Дебаунс (по умолчанию 3 с): ждёт, пока файловая активность не прекратится, прежде чем сработать, чтобы волна параллельных записей агентов не запускала пересборку на каждый файл.

Нажми Ctrl+C, чтобы остановить.

Для агентных сценариев: запускай `--watch` в фоновой вкладке терминала. Изменения кода от волн агентов подхватываются автоматически между волнами. Если агенты также пишут документы или заметки, после этих волн понадобится ручной `/graphify --update`.
