# Справочник graphify: commit-хук и нативная интеграция в CLAUDE.md

Загружай этот файл, когда пользователь попросил установить post-commit-хук или встроить graphify в CLAUDE.md проекта.

## Для git commit-хука

Установи post-commit-хук, который автоматически пересобирает граф после каждого коммита. Фоновый процесс не нужен — срабатывает один раз на коммит, работает с любым редактором.

```bash
graphify hook install    # установить
graphify hook uninstall  # удалить
graphify hook status     # проверить
```

После каждого `git commit` хук определяет, какие файлы кода изменились (через `git diff HEAD~1`), повторно запускает AST-извлечение на этих файлах и пересобирает `graph.json` и `GRAPH_REPORT.md`. Изменения документов/изображений хук игнорирует — для них запусти `/graphify --update` вручную.

Если post-commit-хук уже существует, graphify дописывает к нему, а не заменяет его.

---

## Для нативной интеграции в CLAUDE.md

Выполни один раз для проекта, чтобы graphify был всегда включён в сессиях Claude Code:

```bash
graphify claude install
```

Это записывает секцию `## graphify` в локальный `CLAUDE.md`, которая указывает Claude проверять граф перед ответами на вопросы о кодовой базе и пересобирать его после изменений кода. Ручной `/graphify` в будущих сессиях не понадобится.

```bash
graphify claude uninstall  # удалить секцию
```
